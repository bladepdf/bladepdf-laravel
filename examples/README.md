# BladePDF examples

These examples are designed as realistic starting points rather than minimal syntax demos. Every folder contains a self-contained Blade template, sample data, a rendered preview, and its own usage notes.

| Example | Format | Highlights |
| --- | --- | --- |
| [Invoice](invoice) | A4 portrait | Itemized services, totals, payment terms |
| [Event ticket](ticket) | 200 x 90 mm | Custom paper size, tear-off styling, QR area |
| [Certificate](certificate) | A4 landscape | Formal print layout, signatures, credential id |
| [Business report](report) | A4 portrait | KPI cards, CSS chart, tables, executive summary |
